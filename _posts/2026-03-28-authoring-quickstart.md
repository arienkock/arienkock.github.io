To add a new post:

1. Create a file in `_posts/` named `YYYY-MM-DD-my-slug.md`.
2. Add front-matter at the top:

   ```yaml
   ---
   title: My new post
   subtitle: Optional one-liner
   date: 2026-04-17
   tags: [optional, tags]
   ---
   ```

3. Write Markdown below the front-matter.
4. Commit and push. GitHub Pages will build and deploy automatically.

That's it.
